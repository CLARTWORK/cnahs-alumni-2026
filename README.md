2026. 10. 24.(토) 18:00 정기총회 진행용 웹 슬라이드이다.

## 조작
- 다음 슬라이드: → 키, ↓ 키, Space, Enter, 오른쪽 아래 → 버튼, 휴대폰은 왼쪽으로 밀기
- 이전 슬라이드: ← 키, ↑ 키, 왼쪽 아래 ← 버튼, 휴대폰은 오른쪽으로 밀기
- 처음 / 끝: Home / End
- 전체 화면: F 키
- 특정 슬라이드로 바로 이동: 주소 뒤에 `#번호` (예: `#12`)

## 수정 방법
- 모든 슬라이드는 `index.html` 안의 `<section>` 하나씩이다. 순서대로 배치되어 있으며, 글자는 해당 `<section>` 안에서 바로 고친다.
- 사진은 `images/` 폴더에 있다. 교체할 때는 같은 파일명으로 덮어쓰거나 `<img src="images/파일명.jpg">`를 바꾼다.
- 각 `<section>` 끝의 `<aside>`는 발표자 메모이며 화면에 표시되지 않는다.
- 슬라이드 크기는 1920×1080 기준이며, 창 크기에 맞춰 자동으로 확대·축소된다.

## 게시
GitHub 저장소 Settings → Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 지정하면 `https://<계정>.github.io/<저장소>/` 주소로 열린다.
